# Ejercicio 2: App Shell y Splash Screen

## Objetivo
Construir una interfaz responsiva con header, navegación y contenido principal. El manifest incluye los iconos, `background_color` y `theme_color`, que ayudan a definir la experiencia de lanzamiento.

## Prueba
Abre la aplicación en Chrome, activa la vista móvil desde DevTools > Toggle device toolbar y revisa el diseño. Para comprobar la instalación, usa el menú de Chrome o el icono de instalación cuando esté disponible. La pantalla de inicio nativa depende del navegador, el sistema operativo y las condiciones de instalabilidad; DevTools no garantiza que aparezca una splash screen real en todos los equipos.
