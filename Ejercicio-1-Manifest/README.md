# Ejercicio 1: Web App Manifest y metadatos

## Objetivo
Configurar los metadatos que describen la PWA y añadir iconos PNG de 192×192 y 512×512 píxeles.

## Archivos
- `index.html`: enlaza el manifest y los metadatos.
- `manifest.json`: configura nombre, URL inicial, modo standalone, colores e iconos.
- `styles.css`: interfaz responsiva.
- `icons/`: iconos requeridos.

## Prueba
Ejecuta el proyecto desde `http://localhost/Portafolio-Ejercicios-PWA/Ejercicio-1-Manifest/` y revisa en Chrome DevTools > Application > Manifest. El navegador puede mostrar los requisitos de instalación de forma diferente según su versión y plataforma.
